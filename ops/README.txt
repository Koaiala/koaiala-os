KOAIALA OS 1.0 - PRODUCTION PACK

1) Extraia o pacote sobre C:\PROJETOS\koaiala-os

2) Abra PowerShell COMO ADMINISTRADOR.

3) Execute:
powershell.exe -ExecutionPolicy Bypass -File "C:\PROJETOS\koaiala-os\ops\install_koaiala.ps1"

A tarefa será criada para execução diária às 07:00 (horário de Brasília).

4) Teste imediatamente:
powershell.exe -ExecutionPolicy Bypass -File "C:\PROJETOS\koaiala-os\ops\run_now.ps1"

5) Verifique:
powershell.exe -ExecutionPolicy Bypass -File "C:\PROJETOS\koaiala-os\ops\status.ps1"

O pacote não altera o núcleo analítico.
